# Branch Installation

**Status:** Architecture discussion concluded; implementation acceptance pending.

## Responsibility

Installer confirms the received unit and provides its physical operating environment.

## Standard procedure

1. Check serial, destination and package condition against delivery records.
2. Connect approved power, cooling and wired network; verify bootstrap connectivity prerequisites.
3. Report wrong-site, damaged or suspicious units before activation.

## Completion evidence

Receipt, physical installation and network-readiness record.

## Failure and recovery

Do not infer location from IP address or Site-ID; NEN must authorize the association.
